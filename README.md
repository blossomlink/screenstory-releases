# ScreenStory Releases

Download builds of **ScreenStory** — beautiful screen recordings for macOS.

👉 Grab the latest `ScreenStory-x.y.z.zip` from [Releases](../../releases/latest).

**Install:** unzip → drag ScreenStory.app to Applications → right-click → **Open** on first launch (it's signed with a personal developer certificate, so macOS asks once).

The app checks this repo for updates and offers new versions automatically.
